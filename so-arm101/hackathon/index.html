IL baseline · D_Universal

Opus 5.5 + MCP

Zero demos, no training. Every scene is a new random layout, so every success counts 1.5: 10 runs = 15, scaled to /20. A human checked every run.

Four Architectures, Four Design Philosophies

ACT
~84 M params
Transformer encoder–decoder + CVAE

Properties

  • Action Chunking Transformer (Zhao et al., ALOHA)
  • Trained from scratch, no visual or language priors
  • Predicts a chunk of future actions per observation

Recipe

  • --policy.type=act · 60 000 steps · batch 32
  • Cameras: overhead + wrist
Prediction: should plateau without data scale.
SmolVLA
~450 M params
SmolVLM-2 (256 M) + action expert (~200 M)

Properties

  • Hugging Face open VLA (2025)
  • Pretrained on community LeRobot datasets
  • VLM backbone gives language + visual grounding

Recipe

  • --policy.path=lerobot/smolvla_base · 20 000 steps
  • Full fine-tune on each dataset
Prediction: should benefit from limited data via VLM grounding.
Pi0.5
~3.4 B params
PaliGemma (3 B) + flow-matching action head

Properties

  • Physical Intelligence π₀.₅ (2025)
  • Trained across many robot embodiments
  • High-level VLA reasoning + low-level action expert

Recipe

  • --policy.path=lerobot/pi05_base · BF16 · H200
  • Action expert only, vision encoder frozen · 20 000 steps
Prediction: robust priors but higher inference cost.
Opus 5.5
0 robot demos
Claude Code agent + so101 MCP server (28 tools)

Properties

  • Anthropic’s general-purpose model, never trained on this robot
  • Sees the cameras through tool calls (look, detect)
  • Plans, acts, checks and retries; writes its own skills

Setup

  • Headless claude -p · effort high · robot tools only
  • Same one-line instruction as the IL policies
Prediction: should handle new layouts and setups, but slower and with a cost per run.
DiT excluded after pre-flight (failed in-distribution evaluation). Parameter counts are approximate; Opus’s size is not published.

Seven Skills Claude Wrote for Itself

SkillSavedWhat it does, and why it exists
pick_sponge_to_bowlrun 1First full recipe: hover, align on the wrist image, descend, close, check the grip load, lift, carry, release.
drag_sponge_closerrun 1Sponge out of reach (beyond 33 cm): put the closed gripper behind it and pull it 9 cm back.
hover_low_lookrun 6After missed grasps: hover 4 cm above the sponge and return the wrist image to fine-tune the aim.
grasp_lift_to_bowlrun 6Go down to ~1 cm (2 cm slipped), close, check load ≥ 8 %, lift, carry, release.
grasp_slow_carry_to_bowlrun 14A soft grip slipped at normal speed: the same grasp, then a slow lift and carry.
grasp_lift_lookrun 16After two drops: grasp, lift 3 cm and check the wrist image before carrying.
carry_to_bowlrun 16Slow carry to the saved drop point, then release.

# saved in run 1, used whenever x > 33 cm
drag_sponge_closer(x, y)
  set_gripper 0             # close the jaws
  travel      x, y, z=10
  move_by     dx=+1.5 dz=-6.5  # just beyond it
  move_by     dz=-2.7       # down to the table
  move_by     dx=-9 speed=0.2  # pull 9 cm closer
  move_by     dz=+6         # lift, then re-detect
